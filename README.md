# SOYDGET AI — NALI 2026 Prototype

A lightweight Streamlit prototype for the proposed Human-AI Collaborative Learning Module.

## Run
1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Run: `pip install -r requirements.txt`
4. Start: `streamlit run app.py`

## Important
The prediction function is DEMO logic only. Replace it with a validated ML model trained on the project's actual experimental formulation/sensory dataset.

## Demo flow
Student: Home → Learning Modules → AI Formulation → Prediction → Physical Lab → Sensory Validation

Lecturer: Dashboard → Student Monitoring → Prediction vs Actual
